Enable karne par students official Razorpay UI (UPI, GPay, PhonePe, Cards, NetBanking) se pay kar sakenge. Agar disable rakhenge to testing ke liye direct signup open rahega.
Test mode me dummy cards / UPI se payment test kar sakte hain bina real money kate.

Server-side HMAC-SHA256 signature verification ke liye zaroori hai. (Browser me kabhi reveal nahi hoga)

↗ Open Razorpay API Keys Dashboard

📌 Razorpay Setup Guide:

  1. Razorpay Dashboard par login karein.
  2. Left menu me Account & Settings → API Keys section me jayein.
  3. Generate Key par click karke Key ID aur Key Secret copy karke upar paste karein.
  4. ⚡ Test Razorpay Connection par click karke handshake verify karein.
  5. 💾 Save Razorpay Settings par click karein. Aapka payment gateway live ho jayega!
